# Crowfield v0.9 plan (draft, 2026-10-23; Caleb decides the open points)

v0.9 adds a title screen, music, and a stats page of past runs.

## 1. Title screen (v0.9.0, being built)
- The farm in the background, a few crows circling over it, no farmer.
- A big "CROWFIELD" banner (letters at 3x size with a shadow), the tagline "GROW. DEFEND. SURVIVE.",
  and a blinking PRESS START.
- START begins Day 1. Every ending (won or lost) returns to the title with START, so the stats page can
  live there.
- Dev mode (L + R + B) works on the title too.

## 2. Music (open: which songs, and when they play)
Proposal: four short looping songs, each a melody and a bass line.
| Song | When |
|---|---|
| Title | the title screen |
| Day | while you farm and fight (one song for every normal day) |
| Dusk | the dusk shop (calm, at night with the fireflies) |
| Blood moon | blood moon nights and the final nights (fast, tense) |

How: the GBA's two tone channels (a square wave melody and a soft wave bass) play the music. The sound
clips keep their own channel, so music never cuts a sound effect. The songs are note text in a new
`tools/make_music.py`, with WAV previews you can listen to before they go in the game.
Options: fewer songs (title + one game song), or more (a song per crow stage). Recommendation: the four above.
A mute option: not planned unless you want one.

## 3. Stats page (open: confirm saving this history)
- A second line on the title: STATS. It lists your best run and your last 5 runs: day reached, crops
  grown, crows defeated, and how it ended (WON, FARM LOST, BLOOD MOON, LAST MOON).
- This needs the cart's save memory (SRAM). Only the history is saved; every run still starts fresh, so the
  "no saves" rule stays for runs. Dev mode runs are not recorded.
- Recommendation: best run + last 5. Alternative: only the best run.
