# Crowfield

**Grow. Defend. Survive.** A farming and crow-horde survival game for the Game Boy Advance, made for retro
handhelds and emulators. Version 1.0.

Hungry crows come for your crops every day, stronger and in bigger numbers. Farm, sell your harvest at dusk,
and spend it on weapons, scarecrows, crow cannons and a bigger field. Survive five blood moons and the three
final nights to save the farm.

## Download and play
Get `crowfield.gba` from the [latest release](https://github.com/capnseaaa/Crowfield/releases/latest) and open it
in any GBA emulator. Played and working on R36 handhelds and on iPhone (Delta).

For the game's art and description in your handheld's game list, download `crowfield-art.zip` from the same
release. [docs/INSTALL.md](docs/INSTALL.md) explains where each file goes on the R36, Delta, RetroArch, Onion OS,
NextUI, muOS and EmulationStation setups.

## Controls
| Button | What it does |
|---|---|
| D-pad | Move |
| B (hold) | Run (a tap of B still swings your weapon) |
| A | Plant a seed on empty soil, harvest a ripe crop; load pumpkins into a crow cannon you stand next to |
| A (hold) on soil, or SELECT | Place a scarecrow from your bag, or pick one up |
| R / L | Pick the next / previous seed (corn, carrot, tomato, pumpkin) |
| B | Swing your weapon (the slingshot fires a stone) |
| B (hold) standing still, facing a scarecrow | Switch it off or on |
| START | Start a run on the title screen |

## Building it yourself
Needs `arm-none-eabi-gcc` and Python 3 with Pillow.

```sh
sh crowfield/build.sh          # -> crowfield/crowfield.gba
sh crowfield/tools/package.sh  # -> crowfield/release/ (the card files and crowfield-art.zip)
```

Tests need `libmgba`: `sh crowfield/test/run.sh test/boot.txt` plays a scripted run and saves screenshots.
No external GBA libraries. The art, the title screen and the music are generated by the scripts in
`crowfield/tools/`. Design notes live in `docs/`.
