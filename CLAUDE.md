# CLAUDE.md — Crowfield

Crowfield is a Game Boy Advance horde-survival farming game. It is a sister project to
[Rootflow](https://github.com/capnseaaa/rootflow) and copies its toolchain, layout, and habits.
Target: emulators, mainly the R36 Ultra handheld. Resolution 240x160.

Read these before you plan work:
- `docs/DESIGN.md` — what the game is. Rules, numbers, crow types, upgrades.
- `docs/ROADMAP.md` — versions and the task list. Pick the next unchecked task from here.
- `docs/TECH.md` — VRAM, palettes, sprite budget, save format, the test harness.
- `crowfield/art/concept/concept_sheet.png` — the owner's concept art. Match its mood and palette.

## Layout
```
crowfield/
  build.sh            build the ROM -> crowfield/crowfield.gba
  src/main.c          all game code (one file, like Rootflow)
  src/data.h          GENERATED by tools/build_data.py, never edit, not committed
  src/crt0.s gba.ld   startup code and linker script (copied from Rootflow)
  art/*.png           indexed 16-color PNGs, the source of truth for art
  art/concept/        reference art, not used by the build
  tools/make_art.py   draws art/*.png procedurally (only if missing; --force redraws)
  tools/build_data.py PNGs + farm map -> src/data.h
  tools/fixheader.py  GBA header checksum
  tools/package.sh    SD-card release for the R36
  test/harness.c      headless mGBA runner; test/run.sh builds and runs it
  test/*.txt          scripted input runs
```

## Build and test
```sh
sh crowfield/build.sh                      # needs arm-none-eabi-gcc, python3 + Pillow
sh crowfield/test/run.sh test/boot.txt     # needs libmgba; screenshots land in crowfield/test/
```
In a fresh cloud container: `apt-get install -y gcc-arm-none-eabi libmgba-dev`.

Test script lines: `<frames> <keys> [shot.ppm | @addr,addr | !addr=val]`. Keys are a bitmask:
A=1 B=2 SELECT=4 START=8 RIGHT=16 LEFT=32 UP=64 DOWN=128 (R=256 L=512).
`$name` and `$name+off` resolve to ELF symbols, so tests can read and poke game variables.
One script frame = one game loop (the harness steps by the `frame` symbol). Keep `frame` global.

## Rules for working here
- Always build and run at least `test/boot.txt` before you commit. Look at the screenshots.
  Convert `.ppm` to PNG with Pillow if you need to view them.
- Add a test script for every new feature (`test/<feature>.txt`). Use `@` lines to check values.
- No external GBA libraries (no libtonc, no devkitPro). Plain C, freestanding, `-O2 -mthumb`.
- No floats and no division in hot loops. The ARM7TDMI has neither FPU nor hardware divide.
  Use fixed point (positions are 1/16 pixel) and shifts. `sin64[]` exists for angles.
- Keep game state in plain static globals so tests can find them by name.
- Art: 16-color palettes, 16x16 metatiles and 16x16 sprites. Keep the palette index order fixed;
  the PNGs are edited by hand later. New art goes into `make_art.py` first, then the PNG.
- Commit messages follow Rootflow: `vX.Y.Z area: short summary`, then a plain-language body.
- Bump the version in the commit subject when a ROADMAP milestone item lands.
- README.md speaks to players: short, plain words. Put dev detail in docs/.
- Update `docs/ROADMAP.md` checkboxes and `docs/DESIGN.md` numbers in the same commit as the code.
